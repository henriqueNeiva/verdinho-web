# Página raiz do GitHub Pages

Fonte mantida em D:\projetos\web\github-root, dentro do projeto web.

Destino: repositório henriqueNeiva/henriqueneiva.github.io, raiz da branch de publicação.
URL: https://henriqueneiva.github.io/

A página identifica o responsável e oferece links ao site Verdinho existente. Não usa redirecionamento automático, para manter a tag de verificação diretamente acessível na raiz. Não duplica o site e não altera as URLs institucionais ou o callback OAuth.

A tag foi copiada da página Verdinho já verificada pela conta henriquesneiva@gmail.com. No Search Console, adicione https://henriqueneiva.github.io/ como propriedade de PREFIXO DO URL com a mesma conta, confira a tag exigida e clique em Verificar. Se o Google fornecer um token diferente, preserve o existente e adicione o novo antes de verificar.

Depois da propriedade confirmada, tente novamente o Branding no Google Cloud. Isso não garante aprovação; se o erro continuar, solicite revisão com os comprovantes das duas propriedades e do IAM.

Esta pasta não é incluída no build de dist/ do site Verdinho. Alterações aqui precisam ser enviadas também ao repositório raiz.
